# 逐影 · 像素剑斗

纯 HTML / CSS / JavaScript 的像素即时格斗游戏，支持本机双人、单人陪练和带密码的双人联机房间。Phaser 3.90.0 负责画面呈现；地图、人物、动画和特效由代码绘制。联机由 Node.js 房间服务统一判定，角色和战斗数值独立配置。

## 开始游戏

- 双击 `index.html` 可直接离线游玩，依赖已包含在 `vendor/`。
- 或双击 `launch.cmd`，浏览器打开 `http://127.0.0.1:4173`。
- 首次运行服务时执行 `npm ci`，之后执行 `npm start`，没有编译步骤。推荐 Node.js 22。
- `animation-preview.html` 为动作工坊，可慢放、逐帧检查四个朝向的动作并导出 PNG 图集与 JSON 帧数据。导出帧长为预览速度；实战攻击按实际前摇、命中和收招时间映射播放。

同一局域网中，一人运行服务，其他人访问这台电脑的 `http://局域网IP:4173`，创建房间并通过房间号和密码加入。双方准备后开打。双击 HTML 的离线方式仍可用于本机双人和陪练；房间联机必须连接运行中的服务。

公网发布使用 **GitHub Pages 网页 + Render 免费房间服务**，部署文件已包含。GitHub Pages 本身不运行联机后端。完整步骤与免费额度限制见 [房间联机与部署](docs/deployment.md)。

## 操作

| 玩家 | 移动 / 转向 | 普攻 | 三段剑技 | 格挡 | 闪避 |
| --- | --- | --- | --- | --- | --- |
| P1 | W A S D | J | K | L | 空格 |
| P2 | 方向键 | 1 | 2 | 3 | 0 |

P2 数字键兼容主键盘与数字小键盘（小键盘须开启 Num Lock）。Esc 暂停、Enter 开始或继续。切出窗口自动暂停。联机时每个人使用自己的 WASD / J K L 空格操作分配到的角色，触屏按钮也控制自己的角色。联机暂停和断线由服务统一同步，返回后双方准备再继续。双人同键盘的多键识别能力取决于键盘硬件。

## 第一版规则

- 场地 17 × 11 格，四向即时走格，每 220ms 最多走 1 格；四根石柱和另一位角色不能穿越。
- 双方 200 生命、100 气，每秒自动回气 3，普攻有效命中仍回复 12 气。击倒对手获胜；180 秒结束比较生命，生命相同为平局。
- 普攻前方 1 格、伤害 12、前摇 220ms；有效命中回复 12 气，被弹反不回气。
- 一式「断流」：沿面向直线 3 格，伤害 24、消耗 20 气、前摇 320ms。
- 二式「回岚」：前方两排，每排 3 格，共 6 格，伤害 32、消耗 24 气、前摇 420ms。
- 三式「惊鸿」：前方 3 × 3 格，伤害 44、消耗 30 气、前摇 540ms。
- 每段保存 10 秒；三式结束回到一式。有储存段时单按剑技会等待 230ms 识别双击，快速双击清零且不会释放续段。首段已释放的剑技不会被撤回。
- 双方气条下方显示三个连段格：实际施放一式亮一格、二式亮两格、三式全部亮起，在第三式收招后清空。超时与双击清零同步熄灭；旁边显示下一式和剩余保存时间。
- 格挡窗口 180ms、冷却 800ms。敌方攻击命中时须在攻击范围内且处于有效格挡状态：受到 20% 伤害（整数四舍五入），反击 16 伤害并眩晕敌方 600ms。
- 闪避消耗 18 气、冷却 700ms，沿输入方向或面向移动最多 2 格，不能穿过角色或障碍。普通闪避无敌 180ms。
- 完美闪避仅针对敌方剑技：命中前 220ms 内，从已锁定的攻击范围外闪入范围内，且敌人背后格可站立，才闪现至背后造成 18 伤害，并获得 220ms 无敌。范围内闪到范围内、提前过久、背后受阻均不触发背袭。
- 攻击格在前摇阶段亮阵营色底板：P1 为青蓝色「+」，P2 为朱红色「×」，填色、边框及纹理均区分所有者。范围在出招时锁定。
- 弹反成功触发短促全屏震动、玻璃裂纹与碎片；完美闪避成功触发短暂暗屏、风带与飞叶。仅成功判定触发，全屏反馈不会拦截操作，也不改变战斗时间；暂停和重开清除残留。系统开启减少动态效果时关闭震屏并减轻闪光。
- 碎屏反馈采用较少裂纹和碎片，500ms 内退场；眩晕时显示金色星环、旋转星星、头顶状态标签与剩余时间条，HUD 同步高亮眩晕状态。

首段「竖三格」在本版解释为沿角色面向的纵深直线；二、三段为横向展开的 6 / 9 格，可在 `getAttackCells` 中继续调整。

## 文件与扩展

- `js/combat.js`：独立战斗模拟、角色配置 `CHARACTER_DEFS` 和节奏参数 `CONFIG`。所有时间单位为秒。`Match.act()` 接收输入，`Match.step()` 推进状态。
- `js/pixel-actor.js`：纯代码像素角色动作、关键帧与朝向渲染。
- `js/renderer.js`：Phaser 场景与代码绘制地图、角色、技能预警、粒子。
- `js/screen-fx.js`：成功判定事件驱动的全屏玻璃与飞叶反馈，纯代码绘制。
- `js/app.js`：键盘/触屏输入、开始/暂停/重开、HUD、音效。
- `js/deploy-config.js`：网页房间服务地址；GitHub Pages 工作流按仓库变量生成。
- `server.cjs`、`server/`：静态网页与 WebSocket 房间服务，服务端统一计算战斗结果。
- `.github/workflows/pages.yml`、`render.yaml`：GitHub Pages 与 Render 部署配置。
- `skills/code-pixel-animation/`：本次制作的纯代码像素动画工作流。
- `skills/pixel-duel-rules/`：本项目战斗规范。
- `tools/install-status.md`：工具安装与验证记录。

新增角色从 `CHARACTER_DEFS` 注册开始；动作和外观留在像素动作库，模拟与渲染不互相持有内部状态。联机时客户端发送操作，服务器复用同一套战斗规则并向房间内双方同步状态。

## 验证

`npm test` 验证技能范围、格挡闪避边界、气量、储存/清零、碰撞、双方同时命中，以及房间密码、满员限制、操作归属和断线恢复。

`npm run test:browser` 使用本机 Chrome 完成键盘操作、状态变化、暂停、模式切换、重开与不同屏宽验收。测试截图位于 `artifacts/`。

公网联机手感取决于到服务器的网络延迟，推荐近距离部署或局域网直连。全部动画由代码关键帧组成，可在动作工坊逐帧修改验收。
